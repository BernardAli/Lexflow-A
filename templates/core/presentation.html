What you can demonstrate

Digital PDF/text intake, {% if ocr_enabled %}local scan reading, {% endif %}source evidence, conflicting values, human correction, role-based approval, frozen exports, authenticated HTTP receipts, encrypted case data and a signed audit checkpoint.

Case details and mappings. Additional participants, companies, representatives, properties and office references are encrypted. Primary values stay linked to extraction. Approval freezes the full case and destination mapping versions. An approved-case API returns that frozen case.

Office analytics. Summary, Extraction and review, Workload and timing, and Delivery and audit share receipt-date, workflow, source and cohort filters. Charts include exact-value tables; case links open the underlying records. Elapsed approval time includes waiting and does not measure staff handling time.

What the client pilot adds

The chosen vendor's import schema and test environment; dedicated deployment and operational validation; sanitized office documents; an agreed baseline and acceptance thresholds.

Local PostgreSQL concurrency, encrypted restore and remote scanner/email intake have acceptance drills. Client hosting and the chosen vendor still need acceptance. Native Outlook/Word plugins, SSO and additional hosting profiles remain roadmap items.

Plugin and destination expansion

The existing API supports intake and office-scoped case reads. The remote scanner/email client, approved file exports and signed HTTP handoff are implemented. The current office token is shared across clients; rotating it replaces access for all of them.

The canonical JSON adapter and versioned destination mappings are implemented. ProNotar32 import is not implemented. Its exact product version, supported import contract, accepted sample files and test environment are needed next. Export readiness checks local mappings; it does not prove vendor acceptance.

Integration setup and connection tests, separate scoped plugin credentials, queued delivery and native Outlook/Word/cloud integrations remain planned. Each real destination requires a verified acceptance receipt.
